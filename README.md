# Aegis Lab

Desktop-компаньон для Dota 2: поиск героя, метрики текущей выборки и популярные предметы по стадиям матча.

Версия 0.5 объединяет Windows-установщик и автообновление с новой базой знаний, единым логотипом и сохраняемыми настройками интерфейса.

## Что уже работает

- поиск по полному списку героев;
- портреты и иконки героев из Dota 2 CDN;
- общий винрейт, доля выборов и позиция героя в выборке;
- профессиональные пики, победы и баны, когда они доступны в источнике;
- популярные предметы для старта, ранней, средней и поздней игры;
- локальный кэш API и безопасный Electron preload;
- адаптивный тёмный desktop-интерфейс на русском языке;
- рейтинг меты с фильтрацией по ролям и несколькими вариантами сортировки;
- лидеры винрейта, популярности и «тихие лидеры» с редкими пиками;
- «Радар меты» с распределением героев по коридорам баланса;
- авторский «Индекс Aegis», объединяющий винрейт и присутствие в выборке.
- отдельный план игры для линии, темпа и поздней стадии;
- типовое ядро и ситуационные предметы с пояснениями;
- сильные и опасные матчапы с фильтрацией малых выборок;
- контекстные переходы на выбранного героя в Dota 2 Pro Tracker и Dotabuff.
- автоматическая проверка, загрузка и установка обновлений из GitHub Releases;
- отдельные NSIS-установщик и portable-сборка для Windows.
- интерактивная «База знаний» с шестью учебными модулями, категориями, поиском и глоссарием;
- единый фирменный логотип в интерфейсе, окне и Windows-сборках.
- тёмная и светлая темы, компактный режим и снижение анимаций;
- выбор стартовой страницы и сохранение настроек между запусками;
- переход на страницу поддержки проекта в Boosty.

Активный источник структурированных данных — публичный API [OpenDota](https://www.opendota.com/). Dota 2 Pro Tracker и Dotabuff подключены контекстными ссылками на героя: прямые запросы desktop-клиента блокируются их Cloudflare-защитой, а публичного стабильного API для этих данных нет. Это не маскируется под работающую интеграцию и может быть заменено официальным адаптером позже.

## Запуск

```powershell
npm install
npm run dev
```

## Сборка Windows

```powershell
npm run dist:installer  # установщик с поддержкой автообновлений
npm run dist:portable   # переносимая версия без автообновлений
npm run dist:win        # оба варианта сразу
```

Готовые файлы появятся в `release/`. Для работы автообновления в GitHub Release нужно загружать установщик и создаваемый рядом файл `latest.yml`. Portable-версия обновляется вручную.

## Публикация обновления

Релизы автоматизированы через GitHub Actions. После изменения версии в `package.json` достаточно создать и отправить тег с тем же номером:

```powershell
git tag -a v0.5.0 -m "Aegis Lab v0.5.0"
git push origin main
git push origin v0.5.0
```

Workflow на Windows проверит TypeScript, соберёт оба `.exe` и опубликует установщик, blockmap, `latest.yml` и portable-файл в GitHub Releases. Приложение видит только опубликованные, не черновые релизы.

## Структура

- `electron/main.cjs` — desktop-окно, кэш и адаптер OpenDota;
- `electron/preload.cjs` — безопасный мост между Electron и UI;
- `src/api.ts` — браузерный fallback API;
- `src/App.tsx` — экран поиска, статистики и сборок;
- `src/HeroDetailPanels.tsx` — обзор, ситуационные предметы и матчапы;
- `src/MetaPage.tsx` — аналитическая страница меты;
- `src/KnowledgeBasePage.tsx` — учебные статьи, фильтры и глоссарий;
- `src/styles.css` — визуальная система приложения.
